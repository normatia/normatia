# Normatia

> Plataforma abierta para la consulta y el cumplimiento de la normativa de construcción en España.

Normatia nace con la ambición de convertirse en la fuente de referencia técnica para arquitectos, ingenieros, aparejadores y desarrolladores que trabajan con la normativa constructora española.  

Este repositorio es el corazón del proyecto: un monorepo que contiene todo el material de desarrollo abierto, incluyendo ejemplos de uso de la API, el servidor MCP, skills para asistentes de IA, SDKs oficiales y la documentación técnica.
